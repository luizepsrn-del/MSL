Visual reference

The original static specimen pages from the design-system export, preserved as-is. They are documentation, not the library — the live components are in design-system/components/ and the running showcase is at /design-system.

Serve this folder over HTTP (npm run dev, then /design-system/reference/index.html). The component cards and UI kits compile JSX in the browser, which the file:// protocol blocks.
