Labelled percentage bars, always directly under the donut they explain, in the same order and colours.

```jsx
<MetricBarList items={[
  { label: 'Trucks', value: 57, tone: 'purple' },
  { label: 'Cargo Vans', value: 18, tone: 'green' },
  { label: 'Trailers', value: 9, tone: 'orange' },
  { label: 'Cargo planes', value: 7 },
]} />
```
