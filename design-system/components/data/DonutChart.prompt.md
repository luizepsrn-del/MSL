Segmented ring with a centred figure. Pair it with a MetricBarList underneath, same order and colours.

```jsx
<DonutChart centerValue="100%" centerLabel="Total"
  segments={[{ value: 57, color: 'var(--chart-1)' }, { value: 18, color: 'var(--chart-2)' }, { value: 9, color: 'var(--chart-3)' }, { value: 16, color: 'var(--chart-4)' }]} />
```
