Square icon-only control for top-bar utilities, chat header actions and row overflow menus.

```jsx
<IconButton icon="phone" label="Call" />
<IconButton icon="more-vertical" label="Row actions" variant="ghost" size={28} />
<IconButton icon="send" label="Send" variant="accent" />
```

Always pass `label`. Use `size={44}` on mobile so it clears the tap minimum.
