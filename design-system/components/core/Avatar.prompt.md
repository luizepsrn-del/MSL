Circular person marker; initials fallback when there's no photo (this kit shipped no avatar imagery).

```jsx
<Avatar name="Ronald Richards" size={36} />
<Avatar name="Harrold Tafoya" size={40} status="online" />
```

Sizes in use: 28 (chat message), 36 (top bar, table rows), 40 (chat list), 48 (profile header).
